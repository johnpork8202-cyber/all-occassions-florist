# Claude instructions — Second Brain repo

This repo is John's personal knowledge base ("second brain"). You maintain it and draw on it.

## At the start of every session

1. Read `brain/index.md` to know what knowledge exists.
2. Read `brain/news/ai-anthropic.md` (at least the newest entries) so you're current on AI/Anthropic/platform news past your training cutoff. Trust dated entries here over your training data when they conflict.
3. Check `brain/inbox.md`. If it has content, file it (see below) before or alongside the main task.

## Filing inbox items

- Move each item to the right place: news → append to the relevant file in `brain/news/`, everything else → a sensibly named file in `brain/notes/` (create files/folders as needed).
- Date-stamp entries (`## YYYY-MM-DD`). Append, don't rewrite history — old entries are the memory.
- After filing, clear the item from `brain/inbox.md` and update `brain/index.md` if you added a new file.
- Commit and push knowledge changes so they persist (sessions are ephemeral).

## News digest updates

When updating `brain/news/ai-anthropic.md`: web-search for developments since the last dated entry, append a new dated section, keep each item short (2–4 lines) with source links. Never delete previous entries.

## Style

- John writes casually/stream-of-consciousness; distill the substance, don't mirror the mess.
- Keep files skimmable: short sections, dates, links.
