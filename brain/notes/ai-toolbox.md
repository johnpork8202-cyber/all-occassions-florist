# AI toolbox — other AIs worth using alongside Claude

Free-tier tools that complement the operation. John can run these himself;
Claude can't drive them directly (separate accounts/sessions) but can write
the prompts/scripts to feed them.

## 2026-07-17 — Free-tier landscape

- **Google Gemini (free)** — most generous free tier of any major lab in mid-2026: Gemini 3.5 Flash, voice mode (Gemini Live), Deep Research, NotebookLM, free image gen, monthly Veo video allowance. Best pick when Claude message limits run out or for free video/image needs. ([WhichAIIsBest](https://whichaiisbest.com/best-free-ai/), [PE Collective free-tier comparison](https://pecollective.com/blog/ai-free-tiers-2026/))
- **ChatGPT (free)** — GPT-4o mini default, rate-limited GPT-4o + DALL-E; biggest third-party ecosystem. Note: free tier started showing ads (US Feb 2026, wider by May). Fine as a second drafting opinion. ([The AI Rankings](https://theairankings.com/best-free-ai-tools/))
- **Perplexity (free)** — live web search on every query, ~5 Pro searches/day; best free tool for fact-checking recent events. ([Zapier alternatives roundup](https://zapier.com/blog/chatgpt-alternatives/))
- **ElevenLabs (free)** — 10k characters/month of voice generation. Only relevant if/when the content-channel lane (lane 4) opens; not needed for the Fiverr resume operation. ([DataCamp](https://www.datacamp.com/blog/10-chatgpt-alternatives))
- **Manus** — John mentioned having access ("can make a Claude or ChatGPT in my other AI"); agentic task-runner. Not yet researched in depth; revisit if a concrete use appears. For now the Fiverr operation doesn't need it.
- **Claude (this)** — deep reasoning, long documents, coding; free tier ~15 messages/day, John is on a paid plan via Claude Code sessions. The hub: other tools are spokes.

### How this fits the operation

- Fiverr deliverables: Claude writes them (quality is the product — don't outsource to weaker free models).
- Overflow/simple tasks when limits hit: Gemini free.
- Fact-checking fresh news for the digest: Perplexity (manual) or Claude web search (automatic).
- Voice/video (later, lane 4 only): ElevenLabs free + Gemini's Veo allowance.
- Rule stays: **$0 spent until Fiverr revenue exists.**
